## 📜 My Journey（人生旅途）

> **ADHD** 让我注意力飘，但也给了我爆炸式的联想力和 hyperfocus（聚焦能力） —— 代码、游戏、引擎，都是这么钻进去的。
> **ADHD** made my attention drift, but it also gave me explosive association and hyperfocus-code, games and engines all got in like this!

| Year（年） | What Happened（事件） |
|:----:|---------------|
| **2018** | 🧠 确诊 ADHD · 第一次对「编程」真正着迷——不是上课，是想**做东西** |
| **2018** | 🧠 Diagnosing ADHD, I was really fascinated by "programming" for the first time-not attending classes, but wanting to **make things** |
| **2019** | 🔧 自学编程 · 在一个现在已经死了的社区发作品 · 萌生「要有自己工作室」的念头 |
| **2019** | 🔧 Self-taught programming, publishing works in a community that is now dead, and having the idea of "having your own studio" |
| **2020** | 🍎 **创立果园工作室** · 全国社区排名 **Top 4** · 深入 Scratch · 开学 Python · 迷上了「灵」 |
| **2020** | 🍎 **Established GuoyuanCode**. National Community Ranking **TOP 4** Learn Scratch deeply and start Python. And fell in love with "July" |
| **2024** | 🌐 学前端（HTML/CSS/JS）· 搭个人网站 · 经历轻度抑郁与孤立——**但代码没停** |
| **2024** | 🌐 Learn the HTML/CSS/JS, build a personal website, experience mild depression and isolation-**but the code doesn't stop** |
| **2025** | ☁️ Cloudflare 托管个人域名 · 人际降温让心情更沉，但工作室照转 |
| **2025** | ☁️ I used Cloudflare to host my personal domain name, but the interpersonal cooling made my mood heavier, but the studio continued to open. |
| **2026** | 🚀 新域名 **gybc.top** · 遇到糟心的人事 · **继续写，继续做，继续走** |
| **2026** | 🚀 Buy a new domain name **gybc. top** I'm not afraid of people who have bad intentions, but I will **continue to write, continue to do and continue to walk**  |
