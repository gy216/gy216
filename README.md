## 📜 My Journey

> **ADHD** 让我注意力飘，但也给了我爆炸式的联想力和 hyperfocus —— 代码、游戏、引擎，都是这么钻进去的。

| Year | What Happened |
|:----:|---------------|
| **2018** | 🧠 确诊 ADHD · 第一次对「编程」真正着迷——不是上课，是想**做东西** |
| **2019** | 🔧 自学编程 · 在一个 now-dead 社区发作品 · 萌生「要有自己工作室」的念头 |
| **2020** | 🍎 **创立果园工作室** · 全国社区排名 **Top 4** · 深入 Scratch · 开学 Python · 迷上了「灵」 |
| **2024** | 🌐 学前端（HTML/CSS/JS）· 搭个人网站 · 经历轻度抑郁与孤立——**但代码没停** |
| **2025** | ☁️ Cloudflare 托管个人域名 · 人际降温让心情更沉，但工作室照转 |
| **2026** | 🚀 新域名 **gybc.top** · 遇到糟心的人事 · **继续写，继续做，继续走** |
